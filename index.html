FAQ

Frequently asked questions

What is this page?

A lightweight landing page that combines content, offers and advertising placements.

Can I add my own links?

Yes. Replace each YOUR-OFFER-LINK placeholder with your destination URL.

Where do I add the ad network scripts?

Use the marked Adcash, PopAds and ProPush.me areas. Keep each network's code exactly as supplied by its dashboard and follow its placement requirements.

Can I use this on GitHub Pages?

Yes. This is a static HTML page, so it can be hosted on GitHub Pages or another static host.
